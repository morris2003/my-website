# AI 內訓課程網站

本網站按「課程綱要 → 第幾次課程 → 章節」閱讀。主畫面一次只顯示一個課程或章節。現有 22 章，每章以完整文字說明觀念與實務判斷，依內容使用流程圖、相依關係圖（DAG）、產業分層圖、關聯圖、條列或比較。各章末附檢核問題與對應教材。

第一次課程已納入新增的台灣戰略簡報：AI 五層產業鏈、台積電／鴻海／台達電／聯發科的分工、台灣整體 AI 戰略、企業高層決策，以及 Agent 導入四階段。簡報中的市場數字、未來預測和個別企業敘述是授課時的材料；本網站著重解釋其分析框架，實際決策應重新查核當期資料。

## 檔案

```text
課程網頁/
├─ index.html       網站結構
├─ README.md        維護說明
└─ assets/
   ├─ site.css      沿用第三次課程的淺色側欄風格
   ├─ courses.js     課程、章節名稱、摘要、檢核與教材對照
   ├─ details.js     各章完整內文與圖解資料
   └─ site.js        章節切換、內容圖解與手機版目錄
```

這是純靜態網站。部署 `課程網頁` 資料夾即可，不需要資料庫、外部套件或建置步驟。原始簡報與練習檔仍留在旁邊的各次課程資料夾，網站不提供檔案下載目錄。

## 新增下一次課程

1. 在 `assets/courses.js` 增加下一次課程物件，包含課程摘要、學習成果及各章的 `id`、`title`、`lead`、`checks`、`source`。章節 `id` 使用不重複的格式，例如 `c4-1`。
2. 在 `assets/details.js` 用相同章節 `id` 增加文章區塊。`prose` 適合解釋因果與背景；`bullets` 適合並列判斷；`flow` 呈現步驟；`dag` 呈現多來源相依；`layers` 呈現架構；`relation` 呈現角色或能力關係；`comparison` 僅用於真正需要對照的內容；`scenario` 說明具體應用。
3. 目錄、課程章節清單和上一章／下一章連結會自動產生。新增課程後，逐章核對原始教材、實際開啟頁面檢查圖解與手機版，並確認來源註記。

部分原始簡報內頁的「第二堂課／第三堂課」標記與所在資料夾不一致。網站依 `第一次課程`、`第二次課程`、`第三次課程` 的資料夾順序整理，原始簡報未修改。
